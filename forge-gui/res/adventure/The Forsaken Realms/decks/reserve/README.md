# Reserve decks

Deck lists that were built for an enemy and then replaced or resized by a later tier rebalance
(round 118 first). Nothing in `world/enemies.json` references these files - they are kept, at the
user's request, as ready-made lists for future enemies. `<enemy>_pre_r118.dck` is the list that
enemy ran before round 118's re-pick / resize.
