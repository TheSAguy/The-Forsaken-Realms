## Found after the review (round 173) - not fixed, the user's call

- **Archmage attacks ignore their color.** `TerritoryControl.pickGrandmasterMage(world, color)` filters the biome's
  `getEnemyList()` for Mythic tier; that list carries every catalog enemy, so a color's Mythic-tier attacking mage is
  any of the 56 catalog Archmages (53 arena-exclusive, most off-color), and the Dangerous Enemy chest draws the same way.
- **The player-territory colorless mix-in never fires**: `WorldStage.handleMonsterSpawn()` looks up a biome named
  `"colorless"`; `colorless.json` names it `"waste"`. No retained log holds a `[TFR-ColorlessMix]` line.
